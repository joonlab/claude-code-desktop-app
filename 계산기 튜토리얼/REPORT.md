# 파이썬 계산기 샌드박스 실행 보고서

## 환경
- Python: 3.11.15
- 플랫폼: Linux 6.18.5 (sandbox)
- 작업 디렉터리: `/home/user/claude-code-desktop-app`
- 브랜치: `claude/python-calculator-sandbox-GnKxk`

## 대상 코드
- `calculator.py` — `+`, `-`, `*`, `/`, `**`, `%` 6종 연산을 디스패치하는 `calculate(a, op, b)` 제공
- `test_calculator.py` — 정상 케이스 8건 + 예외 케이스 3건 검증

## 데모 실행 (`python3 calculator.py`)

```
12 + 30 = 42
100 - 47 = 53
8 * 9 = 72
144 / 12 = 12.0
2 ** 10 = 1024
37 % 5 = 2
```

## 테스트 실행 (`python3 test_calculator.py`)

| # | 케이스 | 결과 | 비고 |
|---|---|---|---|
| 1 | 덧셈: 12 + 30 | PASS | 42 |
| 2 | 뺄셈: 100 - 47 | PASS | 53 |
| 3 | 곱셈: 8 * 9 | PASS | 72 |
| 4 | 나눗셈: 144 / 12 | PASS | 12.0 |
| 5 | 거듭제곱: 2 ** 10 | PASS | 1024 |
| 6 | 나머지: 37 % 5 | PASS | 2 |
| 7 | 음수 덧셈: -5 + 3 | PASS | -2 |
| 8 | 실수 곱셈: 0.1 * 0.2 | PASS | 실제값 0.020000000000000004 (math.isclose 허용 오차 내) |
| 9 | 0으로 나눗셈 | PASS | `ZeroDivisionError` 발생 확인 |
| 10 | 0으로 나머지 | PASS | `ZeroDivisionError` 발생 확인 |
| 11 | 지원하지 않는 연산자 | PASS | `ValueError` 발생 확인 |

- 총 11건 / 통과 11 / 실패 0
- 테스트 본체 실행 시간: 약 0.072 ms
- 종료 코드: `0`

## 관찰
- 부동소수점 곱셈(`0.1 * 0.2`)은 IEEE 754 특성상 `0.020000000000000004`이 반환됨. 테스트는 `math.isclose`로 허용 오차를 두어 통과시켰음.
- 0 나눗셈/나머지와 미지원 연산자는 모두 의도된 예외 타입을 발생시킴.

## 결론
샌드박스에서 모든 정상·예외 시나리오가 기대대로 동작했고, 회귀 테스트는 0 ms대에 완료됨.
